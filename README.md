### 🧩 Microservices & Distributed Architectures

- **Hyperlocal Dispatch & Fleet Routing Service:** Modular microservices separating customer ordering (`apps/customer`), real-time logistics commander dispatch (`apps/commander`), driver mobile telemetry (`apps/delivery`), and offline-first merchant desktop POS (`apps/desktop`).
- **Headless WhatsApp Gateway Microservice (`whatsapp-api`):** Decoupled notification microservice deployed on AWS Lambda / Node with resilient Chromium session persistence, automated QR re-authentication, and stateless webhook dispatch.
- **Paytm Payment Bridge Service:** Dedicated payment gateway adapter isolating transaction signing, checksum verification, and webhook status callbacks from core ordering logic.
- **Agentic Team Leader MCP Service (`team-leader-mcp`):** Autonomous orchestration bridge routing tasks to specialized worker instances via standard Model Context Protocol schemas.
